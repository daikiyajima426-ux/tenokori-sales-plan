# 農産物販売プランナー v1.2.2 価格スライダー確認メモ

## 目的

販売計画カードごとに価格を動かし、カード別販売見込み額と全体の目標差がすぐ確認できることを検証する。

## 確認項目

- [ ] 販売計画カードを開いたときだけ価格スライダーが表示される
- [ ] 売値入力欄を変えるとスライダー位置が変わる
- [ ] スライダーを動かすと売値入力欄の値が変わる
- [ ] スライダー上限が100,000円を超えない
- [ ] 売値入力欄では100,000円超も入力できる
- [ ] 100,000円超の価格ではスライダーが最大位置に留まる
- [ ] 100,000円超の価格では「10万円を超える価格は手入力で扱っています」と表示される
- [ ] 0〜1,000円付近では10円単位で動く
- [ ] 1,000〜10,000円付近では100円単位で動く
- [ ] 10,000〜30,000円付近では1,000円単位で動く
- [ ] 30,000〜100,000円付近では10,000円単位で動く
- [ ] スライダー操作で `pricePerUnit` が更新される
- [ ] このカードの販売見込み額が更新される
- [ ] 全体の目標差が更新される
- [ ] 目標到達の参考価格が表示される
- [ ] 現在価格との差が表示される
- [ ] 販売予定数未入力時の案内が表示される
- [ ] 売る形未選択時の案内が表示される
- [ ] 目標金額未入力時の案内が表示される
- [ ] 結果画面にはスライダーが表示されない
- [ ] 在庫注意の表示内容は価格操作で変わらない
- [ ] スマホ幅で横スクロールが出ない
- [ ] schemaVersion が `5` のまま
- [ ] localStorageキーが変更されていない

## 実装メモ

- スライダーは既存の `SalesPlanCard.pricePerUnit` を直接更新する
- データ構造は変更しない
- v1.2.2ではカード別コストやAI助言は扱わない
