# 手残り販売計画 v1.2.0

複数の取れた量・売る形・販売計画をカードとして登録し、全体を合算して今年の目標手残りに届くかを確認する販売計画シミュレーターです。

> 販売計画カードは、取れた量と売る形をつなぐ配分行です。

## 起動

```bash
npm install
npm run dev
```

ビルド確認:

```bash
npm run lint
npm run build
```

スマホ確認用にLANへ出す場合:

```bash
npm run build
npm run start -- -H 0.0.0.0 -p 3107
```

## v1.2.0 の更新内容

- 取れた量カードを複数登録
- 売る形カードを複数登録
- 販売計画カードを複数登録
- 販売計画カードごとの使用量・売上・費用未反映の見込み額を表示
- 全体合算で目標との差と達成率を表示
- 取れた量カード別に販売予定量の超過を表示
- カードの追加、編集、開閉、要約、複製、削除
- 旧v1.0/v1.1保存データをカード形式へ変換

## 保存仕様

保存場所はブラウザのlocalStorageです。既存キーを維持しています。

- `tenokori-sales-plan:v1.0:plan`
- `tenokori-sales-plan:v1.0:harvests`
- `tenokori-sales-plan:v1.0:products`
- `tenokori-sales-plan:v1.0:trials`
- `tenokori-sales-plan:v1.0:settings`

schemaVersion は `5` です。

## JSONバックアップ

「結果」画面の「データ管理」からJSONを出力できます。読み込む場合は「JSON読み込み」を使います。読み込み時は既存データを上書きする確認を挟みます。

読み込めないデータは既存データを変更しません。旧形式は可能な範囲でカード形式へ変換します。

## v1.2.0で実装しないこと

作付面積提案、来年の作付計画提案、栽培技術の助言、AI助言、最適販売パターンの自動判定、カード別コスト構造、課金・公開導線、1ページ型への全面変更は実装していません。

## 既知の制約

- カード別コストはありません。
- 手残りは現時点では費用を引く前の販売見込み額として扱います。
- 保存は単一ブラウザ内のlocalStorageのみです。
