# 手残り販売計画 v0.1.1

農産物の販売単位が袋・房・箱・kgなどで混在していても、現場単位のまま入力し、kg換算・手残り・必要現金との差分を見える化するPWAです。

> 入力は現場単位。比較はkg換算。判断は手残り。

## 起動

```bash
npm install
npm run dev
```

ビルド確認:

```bash
npm run build
```

## 実装範囲

- 基本設定: 作物名、品種名、見込み収量、自家用・贈答・ロス見込み、販売可能量、必要現金、メモ
- 売り方登録: 販路、販売単位、1単位あたりkg、販売価格、費用、メモ
- 販売配分: 売り方ごとの売る数、kg換算量、売上合計、手残り合計
- 結果表示: 総手残り、必要現金との差分、販売可能量との差分、平均kg売価、平均kg手残り
- 必須警告: 量未入力、価格未入力、手残りマイナス、販売可能量超過、必要現金不足
- localStorage自動保存
- JSONエクスポート・インポート
- テキスト出力、印刷用コピー、印刷
- ぶどう想定のサンプルデータ投入
- PWA manifest と Service Worker

## 保存仕様

保存場所はブラウザのlocalStorageです。外部送信、クラウド同期、複数ユーザー管理はありません。

保存キー:

- `tenokori-sales-plan:v0.1:plan`
- `tenokori-sales-plan:v0.1:methods`
- `tenokori-sales-plan:v0.1:items`
- `tenokori-sales-plan:v0.1:settings`

schemaVersion は `1` です。

## JSONバックアップ

「出力」タブからJSONをエクスポートできます。復元する場合は「JSONインポート」を使います。インポート時は既存データを上書きする確認を挟みます。不正なJSONは読み込まず、アプリがクラッシュしないようにしています。

## v0.1で実装しないこと

EC販売機能、顧客管理、請求書発行、厳密な在庫管理、会計ソフト連携、税務処理、AI自動提案、クラウド同期、複数ユーザー管理、決済機能、配送ラベル作成、販売実績分析、年度比較、作業日誌、栽培管理、農薬管理、原価計算の完全対応は実装していません。

## 既知の制約

- 保存は単一ブラウザ内のlocalStorageのみです。
- PDF出力、CSV出力、Googleスプレッドシート連携はありません。
- PWAのオフライン利用は、初回表示後にService Workerが取得した範囲に限られます。
