# 手残り販売計画 v1.0.0

経営1年目でも使える「今年いくら残すか」逆算版の統合検証版です。

今年いくら手元に残したいかを決め、取れた作物をどんな形で売ればその目標に近づくかを、かんたんに試せる農家向け販売計画アプリです。

> 入力は現場単位。比較はkg換算。判断は手元に残るお金。

## 起動

```bash
npm install
npm run dev
```

ビルド確認:

```bash
npm run lint
npm run build
```

スマホ確認用にLANへ出す場合:

```bash
npm run build
npm run start -- -H 0.0.0.0 -p 3105
```

## 実装範囲

- はじめに: 初回ガイドと開始ボタン
- 目標: 作物名、品種名、今年残したいお金、来年の目標、メモ
- 取れた量: 箱、房、kgなどの現場単位入力とkg換算
- 売る形: 中身、売る単位、売値、箱代・袋代、送料、手数料、その他費用
- 売り方を試す: 作る数入力、使う量kg入力、売値調整、すぐ反映される結果
- 結果: 目標との差、取れた量、売る形が決まった量、まだ売り方が決まっていない量、見直す候補
- localStorage自動保存
- JSON出力・読み込み
- テキスト出力、コピー、印刷
- ぶどう想定のサンプルデータ投入
- PWA manifest と Service Worker

## 保存仕様

保存場所はブラウザのlocalStorageです。外部送信、クラウド同期、複数ユーザー管理はありません。

保存キー:

- `tenokori-sales-plan:v1.0:plan`
- `tenokori-sales-plan:v1.0:units`
- `tenokori-sales-plan:v1.0:harvests`
- `tenokori-sales-plan:v1.0:products`
- `tenokori-sales-plan:v1.0:trials`
- `tenokori-sales-plan:v1.0:settings`

schemaVersion は `4` です。

## JSONバックアップ

「結果」画面からJSONを出力できます。読み込む場合は「JSON読み込み」を使います。読み込み時は既存データを上書きする確認を挟みます。

旧形式のJSONを読み込んだ場合は「このデータは旧形式です」と表示し、自動変換は行いません。

## v1.0.0で実装しないこと

EC販売、顧客管理、請求書、厳密な在庫管理、会計ソフト連携、税務処理、クラウド同期、複数ユーザー管理、年度比較、販売実績分析、栽培管理、農薬管理、出荷ラベル作成、配送管理、PDF出力、CSV出力、Googleスプレッドシート連携は実装していません。

## 既知の制約

- 保存は単一ブラウザ内のlocalStorageのみです。
- 旧形式データの自動変換はありません。
- PWAのオフライン利用は、初回表示後にService Workerが取得した範囲に限られます。
- v1.0.0は正式公開版ではなく、統合検証版です。
