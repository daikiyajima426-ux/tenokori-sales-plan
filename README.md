# 農産物販売プランナー v1.2.2

複数の商品構成を組み合わせて、農産物の販売計画が今年の目標手残りに届くかを確認する販売プランナーです。

> 販売計画カードは、取れた量と売る形をつなぐ配分行です。

## 起動

```bash
npm install
npm run dev
```

ビルド確認:

```bash
npm run lint
npm run build
```

スマホ確認用にLANへ出す場合:

```bash
npm run build
npm run start -- -H 0.0.0.0 -p 3107
```

## v1.2.2 の更新内容

- 販売計画カード内に、売値と連動する価格スライダーを追加
- スライダー操作で既存の `pricePerUnit` を更新し、カード別販売見込み額と全体の目標差を即時更新
- カードごとに、目標到達の参考価格、現在価格との差、初心者向けの価格調整目安を表示
- 販売予定数・売る形・目標金額が足りない場合は、価格調整前に何を入れるべきか表示
- schemaVersion と localStorageキーは v1.2.1 から変更なし

## v1.2.1 の更新内容

- 表示名を「農産物販売プランナー」に変更
- 結果画面を、全体結論、確認事項、商品構成、在庫、カード別結果、詳しい数字の順に整理
- カード別結果を要約中心にし、詳細情報は折りたたみ表示へ整理
- 「必要単価の目安」を「全体平均で見た必要単価の目安」に変更
- PWA manifest / metadata / service worker cache名をv1.2.1に更新

## v1.2.0 の更新内容

- 取れた量カードを複数登録
- 売る形カードを複数登録
- 販売計画カードを複数登録
- 販売計画カードに商品役割タグを設定
- 販売計画カードごとの使用量・売上・費用未反映の見込み額を表示
- 全体合算で目標との差と達成率を表示
- 取れた量カード別に販売予定量の超過を表示
- 商品役割ごとの件数・販売見込み・使用量・売上比率を表示
- カードの追加、編集、開閉、要約、複製、削除
- 旧v1.0/v1.1保存データをカード形式へ変換

## 保存仕様

保存場所はブラウザのlocalStorageです。既存キーを維持しています。

- `tenokori-sales-plan:v1.0:plan`
- `tenokori-sales-plan:v1.0:harvests`
- `tenokori-sales-plan:v1.0:products`
- `tenokori-sales-plan:v1.0:trials`
- `tenokori-sales-plan:v1.0:settings`

schemaVersion は `5` です。

販売計画カードの `productRole` がない既存データは、読み込み時に `unset` として補完します。schemaVersion とlocalStorageキーは変更していません。

## JSONバックアップ

「結果」画面の「データ管理」からJSONを出力できます。読み込む場合は「JSON読み込み」を使います。読み込み時は既存データを上書きする確認を挟みます。

読み込めないデータは既存データを変更しません。旧形式は可能な範囲でカード形式へ変換します。

## v1.2.2で実装しないこと

作付面積提案、来年の作付計画提案、栽培技術の助言、AI助言、最適販売パターンの自動判定、カード別コスト構造、課金・公開導線、1ページ型への全面変更は実装していません。

## 既知の制約

- カード別コストはありません。
- 手残りは現時点では費用を引く前の販売見込み額として扱います。
- 保存は単一ブラウザ内のlocalStorageのみです。
