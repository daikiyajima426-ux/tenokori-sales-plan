# 手残り販売計画 v1.2.0

入力済みの内容を要約して閉じ、未入力の項目と結果の読み順を分けた販売計画シミュレーターです。

今年いくら手元に残したいかを決め、取れそうな量、売る形、売値、費用を動かしながら、目標まであとどれくらい必要かを確認できます。

> 入力は現場単位。比較はkg換算。判断は手元に残るお金。

## 起動

```bash
npm install
npm run dev
```

ビルド確認:

```bash
npm run lint
npm run build
```

スマホ確認用にLANへ出す場合:

```bash
npm run build
npm run start -- -H 0.0.0.0 -p 3107
```

## v1.2.0 の更新内容

- 現行6画面構成を維持
- 目標、取れた量、売る形、試す画面に折りたたみ表示を追加
- 入力済みブロックは保存後に閉じ、同じ画面内で要約表示
- 保存後に自動で別画面へ移動しない
- 次に進むべき画面をボタンで明示
- 結果画面を「結論 → 次に動かすこと → 詳しい数字 → 次に決めること → データ管理」の順に整理
- 詳しい数字とデータ管理を折りたたみ化
- 改善シナリオ、まだ決めていない項目、データ管理を分離

## 実装範囲

- はじめに: 初回ガイドと開始ボタン
- 目標: 作物名、品種名、今年残したいお金、来年の目標、メモ
- 取れた量: 箱、房、kgなどの現場単位入力とkg換算
- 売る形: 中身、売る単位、売値、箱代・袋代、送料、手数料、その他費用
- 売り方を試す: 作る数入力、使う量kg入力、売値調整、目標との差
- 結果: 結論、次に動かすこと、詳しい数字、次に決めること、データ管理
- localStorage自動保存
- JSON出力・読み込み
- テキスト出力、コピー、印刷
- ぶどう想定のサンプルデータ投入
- PWA manifest と Service Worker

## 保存仕様

保存場所はブラウザのlocalStorageです。外部送信、クラウド同期、複数ユーザー管理はありません。

保存キー:

- `tenokori-sales-plan:v1.0:plan`
- `tenokori-sales-plan:v1.0:units`
- `tenokori-sales-plan:v1.0:harvests`
- `tenokori-sales-plan:v1.0:products`
- `tenokori-sales-plan:v1.0:trials`
- `tenokori-sales-plan:v1.0:settings`

schemaVersion は `4` です。v1.2.0ではschemaVersionとlocalStorageキーを変更していません。

## JSONバックアップ

「結果」画面の「データ管理」からJSONを出力できます。読み込む場合は「JSON読み込み」を使います。読み込み時は既存データを上書きする確認を挟みます。

旧形式のJSONを読み込んだ場合は「このデータは旧形式です」と表示し、自動変換は行いません。

## v1.2.0で実装しないこと

画面追加、1ページ型への全面変更、AI機能、クラウド同期、課金導線、作付面積の提案、来年の作付計画提案、栽培技術の助言、詳細な経営診断、試算メモ機能、旧形式JSON自動移行は実装していません。

## 既知の制約

- 保存は単一ブラウザ内のlocalStorageのみです。
- 旧形式データの自動変換はありません。
- 開閉状態は画面内状態で、保存対象ではありません。
- PWAのオフライン利用は、初回表示後にService Workerが取得した範囲に限られます。
